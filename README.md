# BicisApp – Incidencias de estaciones (Examen Parcial)

ASP.NET Core MVC (.NET 10) + Identity + EF Core/SQLite. Pantalla `/Operaciones/Incidencias` con login y acción de cierre (rol Supervisor).

Usuarios de prueba (contraseña `Examen2026!`): `supervisor@bicis.pe` (Supervisor), `operador@bicis.pe`.

## Ejecutar
```bash
dotnet run   # http://localhost:5000
```
La base SQLite y los datos de prueba se crean al iniciar.
